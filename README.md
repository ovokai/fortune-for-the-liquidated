A single fortune-cookie message for the freshly liquidated: it opens like the usual reassuring prophecy, then turns the knife with the one thing the trader really had inside them. Wise, second person, and safe to laugh at from zero balance.

The fortune:

> Your fortune lies within. Your leverage got there first.

## Run it

```sh
node main.ts
```
